# rippled RPC methods the SDK deliberately has no request model for.
#
# Read by .ci-config/check-rpc-methods.sh, which compares the method names in rippled's
# src/xrpld/rpc/MethodNames.h with the `Command = "..."` values under Xrpl/. A rippled method
# that is neither implemented nor listed here fails the check.
#
# One method per line: `name  # category: reason`. The category is the first word after `#`:
#
#   admin       Role::ADMIN in the dispatch table (src/xrpld/rpc/detail/Handler.cpp)
#   signing     admin-only unless the node enables public signing; the SDK signs locally
#   cli         command-line wrapper, never dispatched as an RPC method
#   deprecated  documented as deprecated on xrpl.org, or registered for API v1 only
#   internal    public role but undocumented; reports node internals
#   covered     public, but what it does the SDK already does another way
#   gap         public and documented, not implemented yet. Listed so the check stays a
#               signal for methods nobody has looked at; reported as GAP on every run
#
# An entry for a method that is now implemented or no longer exists upstream is reported as
# STALE and fails the check, so the list cannot outlive what it describes.
